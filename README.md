# Hari Prasath S — Portfolio

A modern, interactive developer portfolio built with **React**, **TypeScript**, **Framer Motion**, and **Vite**.

## Features

- 🎨 Developer-themed dark UI with smooth animations
- 💼 Experience & education timelines
- 🛠️ Interactive skills chart with category filters
- 🚀 Live embedded project demos (To-Do List widget, Palette Engine)
- 🖨️ Print-ready resume/CV export
- 💬 Developer message terminal console
- 📱 Fully responsive for mobile, tablet, and desktop

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the dev server:
   ```bash
   npm run dev
   ```

## Tech Stack

- **React** + **TypeScript** — UI components
- **Vite** — Build tool & dev server
- **Framer Motion** — Animations & transitions
- **Lucide React** — Icon library
